The screens below were designed using GOV.UK forms which comes with the following constraints:

  • a maximum of 50 'add another' fields can be added
  • a maximum of 4 upload documents can be added
  • data from a question cannot be passed to another question i.e. a user's name
  • branching is limited to a single route

At the time of writing the above list reflects the applicable contraints when this form was designed. They may not include the current features which may have been introduced after this form was initially designed and put into production.

An end to end flow giving an overview of the entire form is on a mural board. If the link has expired send an email to ucdops@homeoffice.gov.uk to request access.

Lead sponsor application form

Organisations must use this form to apply to be a Lead Sponsor.

Miminum viable product (MVP)

GOV.UK
Screen Description
Start Apply to be a lead sponsor summaries what is needed to complete the application.
GOV.UK form
Organisation screens Description
Eligibility Lead sponsor eligibility requirements. The user is asked if they meet a set of requirements.
Not eligible If the eligibility criteria is not met the user is advised they cannot continue with their application.
Route The user is required to select the route they wish to apply for.
Name The name of the organisation making the application is required.
Charity The applicant is asked if they have a charity number.
Charity number If the applicant has a charity number, it is added.
Company The applicant is asked if they have a company number.
Company number If the applicant has a company number, it is added.
Address The applicant is required to add the registered address of their organisation in the UK.
Website The applicant has the option to add the url of the organisations website.
Consortiums The applicant is asked if they are working with other organisations to make up a consortium capable of delivering the sponsorship.
Consortium names If the user is working with other organisations the applicant is asked to add the name of the other organisation.
Add another consortium name The user is able to add another organisation name.

This question in the prototype enables the user to add 2 additional organisations which would make up the consortium.
Upload document The user is required to upload a document which will explain how their organisation will deliver the lead sponsor role.
Upload successful Confirmation the document has been successfully uploaded.
Board member name The user is required to add the name of a board member.
Board member nationality The user is required to add the nationality of a board member.
Board member passport The user is asked if the board member has a passport.
Board member passport number If the board member has a passport the user is asked to add the passport number.
Board member date of birth The user is required to add board member's date of birth.
Add another board member The user is asked if they wish to add another board member.

The prototype enables the user to add a maximum of 3 board members,
Maximum number of board member reached The maximum number of board member's reached screen is displayed if the user tries to add a 16th board member.

This is not a constraint GOV.UK forms. This is a design decision as we have no idea how many board members an organisation can have.

Key personnel screens Description
Key contact's name A key contact has been defined as the organisation's operational lead.
Key contact's other name The user is asked if the key contact has been known by any other name.
Add key contact's other name If the key contact has been known by another name the user is asked to add that name.
Key contact date of birth The key contact's date of birth is added.
Key contact's nationality The key contact's nationality is selected from an autocomplete input field.

Key contact's passport number Before the user uploads an image of the key contact's passport they are asked to add the passport number.
Key contact's driving licence If the user indicates they will not upload an image of the key contact's passport they are asked if the key contact has a driving licence, and if they will upload an image of it,
Key contact's driving licence number If the user confirms they will upload an image of the key contact's driving licence they are asked to add the driving licence number.
Upload key contact's identity document If the user has indicated they will upload an image of an identity document for the key contact this screen is displayed.

The image will be either the key contact's passport or driving licence.
Upload successful Screen displayed confirming the upload of the identity document has been successful for the key contact.

The image will be either the key contact's passport or driving licence.
Key contact's email The user is required to add the key contact's email.
